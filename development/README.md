# Development Notes

This directory documents the development process and model logic behind the
Sinhala Stem Segmenter.

Files:

- `logic.md`: training and segmentation logic.
- `score_formula.md`: exact split scoring formula.
- `training_and_testing.md`: training/testing process and evaluation approach.
- `export_model_tables.py`: regenerates `data/suffix_frequencies.tsv` and
  `data/stems.tsv` from the bundled model.

The main user-facing README stays short. This directory keeps the advanced
details for researchers, developers, and contributors.
