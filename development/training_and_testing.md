# Training And Testing

The bundled model was trained from large modern Sinhala text collections,
including Sinhala news text and broad Sinhala web text. The goal was to learn
high-coverage modern written Sinhala stem/rest patterns without manually
encoding grammatical suffix rules.

## Training Process

1. Collect modern written Sinhala text.
2. Normalize text with NFC normalization.
3. Extract Sinhala word tokens.
4. Convert each word into Sinhala orthographic clusters.
5. Generate legal split candidates for each word.
6. Count stem candidates, rest/suffix candidates, and stem-family frequencies.
7. Merge frequency evidence from the training collections.
8. Compress the final model as:

```text
src/sinhala_stem_segmenter/resources/default.model.json.gz
```

## Exported Tables

The bundled model was also exported into human-readable TSV files:

```text
data/suffix_frequencies.tsv
data/stems.tsv
```

The exported files contain:

- `461,704` learned rest/suffix candidates with frequencies.
- `811,966` learned stem candidates with support counts.

These are generated by:

```bash
python3 development/export_model_tables.py
```

## Testing Process

Testing focuses on structural correctness and usability:

- every segmented result preserves the normalized word
- splits occur only at legal Sinhala cluster boundaries
- unknown or unsupported short words can remain unsplit
- custom models can be saved and loaded
- the command-line tool can use the bundled default model

## Evaluation Notes

The model is data-driven and unsupervised. Evaluation therefore checks
reconstruction and boundary safety rather than claiming perfect linguistic
accuracy.

Useful quality signals include:

- `split_coverage`: how often the model finds a split
- `family_supported_split_rate`: how often a split has strong family evidence
- `average_split_confidence`: average model confidence for split words
- `average_rest_clusters`: typical size of the right-side segment

These metrics are model-support signals. A linguist-created gold dataset would
be needed for formal linguistic accuracy scores.
